# Make Some Noise

ノイズを選んで、重ねて、つくる。ブラウザだけで動く、日本語のノイズ素材制作・画像加工スタジオです。

## 起動

Node.js 22.12以上（または24以上）とnpmを使用します。

```sh
npm ci
npm run dev
```

表示されたローカルURLを開きます。サーバーは `127.0.0.1` のみに公開します。

```sh
npm test       # シード・設定形式・履歴・分布の単体テスト
npm run build # 型検査と本番ビルド
npm run preview
```

## 使い方

1. 左の見本をクリックしてノイズを追加します。プリセットは現在のレイヤーを置き換えます。
2. 右のレイヤーを選び、大きさ・強さ・色・不透明度を調整します。上のレイヤーほど手前です。
3. 画像を加工する場合は「画像を読み込む」、または中央へドラッグ＆ドロップします。
4. 共通シードを変えると模様が変わります。レイヤーの鍵を閉じると、その模様だけ固定できます。
5. 再生ボタンで動きを試し、時刻を決めて「PNGを書き出す」を押します。
6. 作業を続ける場合は「設定を保存」でJSONを保存してください。ページの再読み込み後は「設定を開く」で復元できます。

Ctrl+Zで元に戻す、Ctrl+Shift+ZまたはCtrl+Yでやり直す。入力欄以外ではSpaceで再生・停止できます。履歴は50操作、レイヤーは50枚までです。

### 対応する表現

- **粒状**：均一、ガウス、塩胡椒。白黒・RGB独立・指定色。
- **パターン**：Value、Perlin、Simplex、Worley、フラクタル雲、乱流、マーブル。
- **フィルム**：グレイン、縦傷、ほこり、ちらつき、フィルムダメージ、カラーフィルム。
- **アナログ**：走査線、水平同期ずれ、RGB色ずれ、ブロックグリッチ、RGBシグナル、グリッチフレア。
- **テクスチャ**：紙の繊維、ディザ風ドット、グランジスクラッチ。
- **プリセット**：古い映画、VHS、印刷の粒、雲、紙、カラースタティック、ダークグランジ、ダストフィルム、RGBシグナル、クロマブロック、グリッチフレア、カラーフィルム。

合計28種類・14プリセット。追加のグランジ／信号／フィルム素材も、画像ファイルを使わずシードから生成します。RGBシグナルとグリッチフレアは元画像がなくても発光する素材を作れます。白黒・RGB・指定色を切り替えられます。

フィルムダメージ、RGBシグナル、グリッチフレア、カラーフィルムは部分透明の素材です。「背景を除いて保存」で重ね合わせ用PNGを生成できます。グランジスクラッチは表面全体を覆うため、不透明度やスクリーン／ソフトライト合成で調整してください。プリセットの黒・茶色の背景は完成画像に含まれますが、背景を除いた素材には含まれません。

通常・乗算・スクリーン・オーバーレイ・ソフトライトで合成できます。同期ずれ・色ずれ・グリッチは、下の合成画像を変形するため合成方法を変更できません。不透明度で効果量を調整します。

### シードと再現性

同じアプリのバージョン・実行環境・寸法・時刻・ノイズ設定・シードで再現します。種類ごとに共通シードから乱数系列を作るため、レイヤーの並べ替えや作り直しで乱数配置は変わりません。同じ種類のレイヤーを別の模様にしたい場合は、そのレイヤーのシードを固定し数値を変更してください。複製は元の有効シードを固定して模様を保持します。

ガウスノイズはBox–Muller法です。平均0.5、シグマを指定した明るさを0〜1に制限します。シグマが大きいほど端でクリップされ、粒の密度を下げた場合は一部を中間色に置き換えます。このため最終画像の標準偏差が常に指定シグマと等しいわけではありません。

### 画像・書き出し

- PNG・JPEG・WebP（40MB以下）を読み込みます。長辺が端末上限を超える画像は縮小します。
- 初回読み込みでは画像の寸法に合わせます。設定JSONで元画像を再選択するときは保存済みのキャンバス寸法を保持します。サイズ変更後は中央に全体が収まるよう配置します。
- 出力は各辺64〜4096px。GPUのテクスチャ・描画バッファ上限も確認します。メモリ不足時はサイズを下げてください。
- フィット表示は長辺1024px以下で軽量描画します。100%以上の表示では出力解像度で描画し、スクロールして細部を確認できます。保存時は常に指定寸法です。
- 「背景を除いて保存」は画像と単色背景を取り除きます。雲など画面を覆うレイヤーは不透明なままです。縦傷やほこりは透明素材として使用できます。
- PNG生成後にダウンロードを開始し、生成画像と保存リンクを残します。アプリ内ブラウザで保存が始まらない場合は、同じローカルURLを通常のブラウザで開いてください。
- 設定JSON（形式 `make-some-noise`、バージョン1）はレイヤー、色、シード、時刻、速度、寸法を含みます。元画像やUndo履歴は含みません。画像は再選択が必要です。

## 実装

React / TypeScript / Vite / WebGL2。通信API、アカウント、AIモデルは不要で、読み込んだ画像を送信しません。フォントも端末のシステムフォントです。

`src/catalog.ts` に説明・調整項目・初期値・プリセット、`src/renderer.ts` に生成と合成、`src/project.ts` に設定検証・履歴・シードをまとめています。新しいノイズを追加する場合は `NoiseKind`、カタログ、シェーダーの種類分岐を同時に更新し、描画チェックに追加してください。

GPUのテストは開発サーバーの `/?diagnostics` から実行できます。`/?playback-check` は編集画面を5秒再生して実際のフレーム数を測ります。本番ビルドには検証画面を含めません。テスト用画像・JSONは `tests/fixtures` にあります。

## 初版の範囲と検証

静止画制作と動くプレビューに対応します。動画入出力、音声ノイズ、AI画像生成、潜在テンソル出力、完全なシームレス生成、Photoshopとの完全一致は対象外です。GPUやブラウザをまたぐピクセル完全一致も保証しません。

検証結果と未確認事項は [docs/VALIDATION.md](docs/VALIDATION.md) を参照してください。コミット・公開デプロイは行っていません。


### 生成エラー風の素材

- **生成崩壊ブルーム**（パターン）：黒い隙間と、白く飽和した虹色の塊。「塊の大きさ」「色のあふれ」「形の崩れ」を調整できます。プリセット名は「生成エラー」です。
- **デコード崩れ**（アナログ）：細かなRGBノイズの中に、時間で変わる色帯が現れます。「粒の大きさ」「色帯の強さ」「色帯の数」を調整できます。プリセット名は「壊れたデコード」です。

どちらもAIモデルや潜在データを使用しない、生成失敗の見た目を模した手続き生成です。白黒・RGB・指定色、シード、時刻、PNGと設定保存に対応します。黒い部分を含む不透明な素材なので、画像に重ねる場合はスクリーン／ソフトライトや不透明度を使います。動画の入力・書き出しは含みません。


### カラー砂嵐

「粒状」カテゴリの「カラー砂嵐」は、デコード崩れの色帯の強さを0にした砂嵐を独立させたものです。同じ共通シード・粒の大きさ・時刻・速度なら、初期コントラスト0.78・明るさ4で元と同じ粒になります。粒の大きさ・コントラスト・明るさと色モードを調整でき、色帯は生成しません。
